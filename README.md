# Student Tasks App

A simple Flutter application created for Git and GitHub training.

## Features
- Simple and clean UI
- Task cards display
- Organized Flutter project structure
- Git and GitHub workflow implementation

## Technologies Used
- Flutter
- Dart
- Git
- GitHub

## Project Structure
lib/
├── screens/
│ └── home_screen.dart
├── widgets/
└── main.dart

## GitHub Features Used
- Repository Creation
- Branches
- Commits
- Pull Requests
- Issues

## How to Run
1. Clone the repository
2. Run flutter pub get
3. Run flutter run
